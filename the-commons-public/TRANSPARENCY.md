# Development transparency

The Commons was co-developed through an extended conversation between a human experimenter and ChatGPT.

- ChatGPT proposed experimental designs, generated most of the Python code, helped debug local execution, and analyzed the reports.
- The human experimenter ran the programs locally, paid API costs, preserved the outputs, decided which experiments to run, and requested this public package.
- Recorded experimental branches in v0.2–v0.5 used `gpt-5.6-luna` according to the reports.
- The reports under `reports/` are preserved experiment outputs rather than rewritten summaries.
- Private conversation logs, API keys, local databases, and private branch-memory databases are intentionally excluded.

This project is exploratory and was not preregistered. The sequence of versions was adaptive: later experiments were designed after observing earlier results and failures. That is scientifically useful for prototype development, but it means the sequence should not be read as a confirmatory preregistered study.
