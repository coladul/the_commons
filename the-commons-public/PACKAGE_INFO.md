# Public package information

This snapshot packages The Commons v0.1–v0.5 for outside review.

Included:

- exact experiment scripts for v0.1–v0.5;
- `genesis_record.md`;
- exact preserved Markdown reports for v0.2–v0.5;
- plain-language and technical documentation;
- machine-readable summary CSVs;
- a SHA-256 manifest.

Intentionally excluded:

- API keys and `.env` files;
- virtual environments;
- local SQLite databases;
- private branch-session databases;
- private conversation history.

The public summary was assembled after v0.5. It is not itself an experimental output; the files under `reports/` are the preserved records of the runs.
